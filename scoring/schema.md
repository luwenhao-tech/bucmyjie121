# 文献可信度评分 Schema · 桑白皮方法学审查框架

## 打分对象
按 `filename` 为单位，对 111 个源文件各打一份。
（不按 chunk 打，同一文件的所有 chunk 共享同一份分数。）

## 5 个维度

| 维度 | 权重 | 说明 |
|---|---|---|
| `study_type_score` | 0.30 | 文献类型：药典/团标=1.0，Meta=0.9，RCT=0.85，原始实验=0.7，综述=0.5，本草考证/科普=0.4，会议摘要/学位=0.5 |
| `journal_tier_score` | 0.25 | 期刊层级：SCI Q1=1.0，SCI Q2=0.85，CSCD 核心=0.75，北大核心=0.6，普刊=0.4，学位论文=0.5，官方标准=1.0 |
| `methodology_score` | 0.20 | 方法学完整度：checklist 命中率（详见下方 checklist），全命中=1.0 |
| `recency_score` | 0.15 | 时效性：≤5年=1.0，5–10年=0.8，10–20年=0.6，>20年=0.4；本草考证/药典历史类不降权=1.0 |
| `consensus_score` | 0.10 | 共识度：结论是否与主流一致（LLM 判断，无法判断给 0.6 默认值） |

## 综合分
```
credibility = 0.30*study_type + 0.25*journal_tier + 0.20*methodology + 0.15*recency + 0.10*consensus
```
分档：
- **A 类**：credibility ≥ 0.85（药典、团标、高分区 SCI 原始研究）
- **B 类**：0.60 ≤ credibility < 0.85（核心期刊原始实验、方法学基本完整的综述）
- **C 类**：credibility < 0.60（普刊、方法学缺失、时效差）

## 方法学 checklist（桑白皮质量评价类通用，命中一项 +1/N）

对于**质量评价/含量测定/HPLC/UPLC 类论文**：
1. 是否交代样品来源（产地、批号、采收时间）
2. 是否有对照品来源与纯度说明
3. 色谱条件是否完整（柱型号、流动相、检测波长、柱温、流速、进样量）
4. 是否有系统适用性试验（理论塔板数、分离度）
5. 是否有方法学验证（线性、精密度、重复性、稳定性、加样回收率、检测限）
6. RSD 是否报告且 ≤ 3%
7. 是否设置对照（阴性/空白/替代品）
8. 样本量是否 ≥ 3 批

对于**药理/活性/化学成分类论文**：
1. 是否说明提取分离流程
2. 是否有结构鉴定手段（NMR/MS 等）
3. 是否设置阳性/阴性对照
4. 是否交代动物/细胞来源与伦理
5. 是否报告剂量-效应关系
6. 是否有生物学重复（n ≥ 3）
7. 是否给出统计方法
8. 是否讨论作用机制

综述/药典/团标不套 checklist，methodology 直接给 1.0（药典/团标）或按内容深度给 0.5–0.7（综述）。

## 打分数据源
- 文本：从 `papers_index.json` 里取该 filename 下**首个 chunk（若英文 PDF 存在 【中文摘要】chunk，优先它）+ 后续 chunk 各截前 500 字拼接**，总长 ≤ 3000 字
- 若是 docx（药典/团标类），取前 2000 字即可
- filename 本身也交给 LLM 参考（含年份/药材名/主题线索）
